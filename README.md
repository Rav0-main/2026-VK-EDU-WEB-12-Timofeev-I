## Домашнее задание №2.

**Чтобы запустить** локальный сервер django:
1. **На собственной машине**: требуется **активировать** виртуальное окружение **Python**, **установить** зависимости `requirements.txt` и запустить сервер командой: 
```
python manage.py runserver
```

2. С использованием **docker**. Ввести команду:
```
docker compose up --build
```
